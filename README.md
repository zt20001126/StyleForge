# StyleForge

StyleForge is an MVP project for AI-assisted visual creation, including text-to-image, image-to-image, and text-to-video generation workflows.

The project is organized as a separated frontend and backend application:

- `backend/`: FastAPI backend for APIs, services, schemas, and configuration.
- `frontend/`: Native HTML/CSS/JS single-page application.

Current status: project structure scaffold only, with implementation to be added later.
